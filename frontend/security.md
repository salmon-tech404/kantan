### SEC-AI-002 · `must` · T1 critical
**Output Sanitization of LLM Generated Content**

All Markdown and HTML responses generated by the LLM must be sanitized using DOMPurify before rendering into the client DOM.

How to: Wrap client Markdown rendering: <div dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(marked(content)) }} />.

✗ div.innerHTML = llmGeneratedResponse; // High severity XSS vulnerability
✓ const cleanHtml = DOMPurify.sanitize(rawHtml);

**Why:** An LLM manipulated by prompt injection or repeating malicious input can emit <script>, <iframe>, or onerror XSS vectors that execute in the user browser.
